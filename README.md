# 📚 Библиотека. Управление бизнес-процессами

> Веб‑приложение для автоматизации работы библиотеки: учёт книг, читателей, выдача/возврат, закупки, отчёты, управление сотрудниками (администратор и библиотекарь).

![GlassFish](https://img.shields.io/badge/GlassFish-4.1.2-green)

---

## 🚀 Возможности

- **Авторизация сотрудников** (администратор / библиотекарь) – самостоятельная регистрация отсутствует.
- **Управление книгами** (добавление, редактирование, удаление, поиск по названию/автору).
- **Управление читателями** (регистрация, читательские карточки с уникальным номером).
- **Выдача и возврат книг** с автоматическим расчётом срока возврата (14 дней) и контролем доступности.
- **Заявки на закупку новых книг** – создание заявок, приём поступления и автоматическое пополнение фонда.
- **Отчёты** – общее количество книг/читателей, активные выдачи, просрочки, топ-5 популярных книг.
- **Управление сотрудниками** (только для администратора): добавление/удаление библиотекарей и администраторов.

---

## 🛠 Технологии

- **Backend**: Java 8+, Java Servlets, JSP, JDBC
- **Frontend**: HTML5, CSS3 (адаптивный дизайн, современные тени, скругления)
- **База данных**: MySQL 8.0
- **Сервер приложений**: GlassFish 4.1.2 / Tomcat 8+
- **Сборка**: обычная структура веб-приложения (без Maven)

## 👥 Роли пользователей

| Роль | Права |
|------|-------|
| **Администратор** | Полный доступ: управление книгами, читателями, выдача/возврат, закупки, отчёты, а также создание и удаление учётных записей сотрудников (библиотекарей и других администраторов). |
| **Библиотекарь** | Всё, кроме управления сотрудниками (раздел «Сотрудники» недоступен). |

> Первоначальные учётные записи создаются через SQL‑скрипт:  
> - `admin` / `admin`  
> - `librarian` / `librarian`
